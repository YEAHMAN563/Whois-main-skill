# Contributing

Thanks for helping improve Reverse Master. Contributions should make the workflow more accurate, reproducible, clear, and safe.

## Good contributions

- Correct technical inaccuracies and stale tool/version references.
- Improve evidence requirements, validation steps, and reporting templates.
- Add platform-specific notes with authoritative references.
- Improve clarity without making the skill assume tools or licenses that may not exist.
- Add safe, non-sensitive examples that do not contain proprietary code or live malware.

## Before submitting

1. Explain the problem and the expected improvement.
2. Keep changes focused and update the README if user-facing scope changes.
3. Verify section references, headings, and Markdown formatting.
4. Separate observed facts from assumptions and cite external technical claims where practical.
5. Do not add credentials, private data, proprietary binaries, or live secrets.

## Pull requests

Describe the motivation, summarize the changes, list any technical claims that need review, and note what you tested.
